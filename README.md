# Grand Banquet Hall Survey Portal

A low-cost, serverless **AWS Banquet Hall Survey Portal** built with Terraform, Amazon S3, CloudFront, Cognito, API Gateway, AWS Lambda, and DynamoDB.

The application allows visitors to create an account, verify their email, sign in, view banquet-hall plans/tariffs/facilities, and submit an event survey.

## Architecture

```text
                         Internet
                            |
                            v
                    Amazon CloudFront
                            |
                            v
                     Amazon S3
                   (Static Website)
                            |
             +--------------+--------------+
             |                             |
             v                             v
      Amazon Cognito                 API Gateway HTTP API
      User Authentication                    |
                                             |
                                      JWT Authorizer
                                             |
                                             v
                                        AWS Lambda
                                             |
                                             v
                                         DynamoDB
                                    +--------+--------+
                                    |                 |
                                  Users             Survey
```

### AWS services used

| Service | Purpose |
|---|---|
| **Amazon S3** | Stores the frontend `index.html` and generated `config.js` |
| **Amazon CloudFront** | HTTPS/CDN distribution for the frontend |
| **Amazon Cognito** | User registration, email verification, login, and JWT authentication |
| **API Gateway HTTP API** | Provides authenticated REST-style API endpoints |
| **AWS Lambda** | Python backend/API processing |
| **Amazon DynamoDB** | Stores user and survey information |
| **AWS IAM** | Grants Lambda access to DynamoDB and CloudWatch Logs |
| **Amazon CloudWatch Logs** | Lambda logging |
| **Terraform** | Infrastructure as Code |
| **Random provider** | Adds a unique suffix to AWS resource names |
| **Archive provider** | Packages the Lambda Python file into a ZIP |

## How the Application Works

### 1. User registration

The frontend uses the Amazon Cognito JavaScript SDK.

A new user provides:

```text
Full name
Email
Phone
Password
```

The frontend calls Cognito's sign-up operation.

### 2. Email verification

Cognito sends a verification code to the user's email.

The user enters the code in the frontend.

After successful verification, the user can sign in.

### 3. Login

After successful login, Cognito returns an ID token.

The frontend stores the JWT token in memory and sends it to the API using:

```http
Authorization: <JWT_TOKEN>
```

### 4. API authentication

API Gateway validates the JWT using the Cognito JWT authorizer.

Only authenticated requests can access:

```text
GET  /info
GET  /me
POST /survey
```

### 5. User data

The Lambda function reads the authenticated user's Cognito claims and stores/updates the user record in the Users DynamoDB table.

### 6. Survey submission

The browser sends the survey data to:

```http
POST /survey
```

Lambda validates the required fields and stores the submission in DynamoDB.

## Security

The architecture uses several security controls:

- S3 public access is blocked.
- CloudFront accesses the S3 bucket through Origin Access Control.
- Frontend traffic is redirected to HTTPS.
- API endpoints are protected by Cognito JWT authentication.
- Lambda receives the authenticated user's Cognito claims.
- IAM permissions are scoped to the required DynamoDB tables and CloudWatch logs.
- DynamoDB point-in-time recovery is enabled.
- API Gateway has throttling configured.
- Password requirements require at least 8 characters, including uppercase, lowercase, and numbers.

### Important production considerations

Before using this application in production, consider adding:

- AWS WAF
- Custom CloudFront domain and ACM certificate
- More restrictive IAM policies
- Input validation and stronger business validation
- CloudWatch alarms
- Structured application logging
- Secrets/configuration management where applicable
- Rate limiting appropriate for the expected traffic
- Backup/retention policies
- CI/CD deployment
- Security monitoring
- Privacy and data-retention policies

## Cost Considerations

This architecture is designed as a low-cost serverless deployment.

The Terraform configuration uses:

- DynamoDB `PAY_PER_REQUEST`
- Lambda ARM64
- CloudFront `PriceClass_200`
- Small Lambda memory allocation
- 14-day CloudWatch log retention

Actual AWS costs depend on traffic, storage, requests, data transfer, CloudFront usage, Cognito usage, and other account-level factors.

Always check current AWS pricing before using the system at scale.

## Troubleshooting

### Terraform says `web/index.html` does not exist

Check:

```powershell
Test-Path .\web\index.html
```

If the file is currently in the project root:

```powershell
mkdir web
Move-Item .\index.html .\web\index.html
```

### Terraform says `lambda/app.py` does not exist

Check:

```powershell
Test-Path .\lambda\app.py
```

If necessary:

```powershell
mkdir lambda
Move-Item .\app.py .\lambda\app.py
```

### Frontend loads but API calls fail

Check:

1. `terraform output -raw api_url`
2. Browser developer console
3. API Gateway routes
4. Cognito User Pool
5. JWT authorizer
6. Lambda CloudWatch logs
7. CloudFront URL configured in API Gateway CORS

### Login fails

Check:

- Cognito user has been email verified.
- Email/password are correct.
- Cognito User Pool Client exists.
- Browser console for JavaScript errors.
- Generated `config.js` contains the expected User Pool ID and Client ID.

### Survey submission fails

Check:

- User is authenticated.
- JWT is being sent in the `Authorization` header.
- `event_type` and `expected_guests` are populated.
- Lambda has DynamoDB permissions.
- `USERS_TABLE` and `SURVEY_TABLE` environment variables are present.
- CloudWatch logs for Lambda errors.
